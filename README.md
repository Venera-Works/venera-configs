# 轻书架 Venera 漫画源

本仓库维护适用于 Venera / VeneraNext 的轻书架漫画源配置，版本信息以 `index.json` 中的元数据为准。

> 使用前需要轻书架账号，并在漫画源设置中完成登录。

## 功能

### 浏览与搜索

- 发现页包含最近更新、热门漫画和阅读历史。
- 最近更新、热门漫画和阅读历史支持分类分页，每页 24 项。
- 支持模糊、精确、书名、作者、系列名和标签六种搜索模式。
- 搜索时可选择忽略日文原文或 AI 内容。

### 阅读与互动

- 展示系列简介、封面、原名、作者、标签及更新时间。
- 按轻书架上传源组织章节分组，并加载完整章节图片。
- 支持查看系列评论与回复，以及发表评论和回复。

### 账号

- 支持使用轻书架注册邮箱和密码登录。
- 支持签到。

### 网络收藏（官方书架）

- 对接官方书架（20260921 规范），支持浏览已有多级目录并管理漫画收藏。

## 安装与首次使用

1. 在 Venera / VeneraNext 中添加本仓库索引，或导入 [`lightnovelshelf.js`](./lightnovelshelf.js)。
   - 索引地址：`https://cdn.jsdelivr.net/gh/miludeshiji/venera-configs@main/index.json`
   - 源文件地址：`https://cdn.jsdelivr.net/gh/miludeshiji/venera-configs@main/lightnovelshelf.js`
2. 登录：
   邮箱登录：打开账号登录，输入轻书架注册邮箱和密码。
   Token 登录：在源设置中选择“Token 登录”，输入 `RefreshToken|x-id`；`x-id` 仅去除首尾空白，不会被改写。

## 官方书架（网络收藏）使用说明

### 进入与操作
- **浏览**：在“网络收藏”中打开轻书架即可浏览“根目录”（虚拟入口）与远程多级文件夹（按层级路径展示）；列表按漫画（`Book.Id`）独立分页呈现。
- **添加与移除**：在漫画详情页收藏面板中点击对应目录加入或移出。
- **跨目录移动**：因一部漫画同一时间仅归属于一个目录（`singleFolderForSingleComic=true`），已有收藏时详情面板会禁用其他目录按钮。现有 UI 下须**先点击旧目录移出，再点击目标目录加入**（源底层已支持直接移动回调，但界面暂不可直接触发）。

### 限制与范围说明
- **只展示/修改 COMIC**：本源仅管理漫画，轻小说不会出现在列表中；保存完整书架时保留 `NOVEL/FOLDER`，不会覆盖或删除小说。
- **目录维护**：客户端内暂不支持新建、删除、重命名或排序远程文件夹，如需维护请前往官方 Web 端。

### 安全提示与注意事项
- **全量快照保存**：书架修改为全量快照提交。跨客户端同时修改可能覆盖各自更改，建议操作前重新打开网络收藏／重新加载并核对官方 Web，避免并发操作。
- **写断线与重试策略**：保存时若发生网络超时或断线，因无法确定服务端实际持久化结果，源**不会自动重试**。若遇失败，请重新打开网络收藏／重新加载并核对官方 Web 确认真实状态后再行操作。

## 设置

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| API 线路 | 在 `HK / 默认` 与 `Cloudflare` 线路之间切换 | `HK / 默认` |
| 搜索时忽略日文原文 | 从搜索结果中过滤日文原文 | 关闭 |
| 搜索时忽略 AI 内容 | 从搜索结果中过滤 AI 内容 | 关闭 |
| 手动签到 | 立即发起一次签到 | 按需使用 |
